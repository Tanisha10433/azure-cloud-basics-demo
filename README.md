# Microsoft Azure Cloud Demo

This project demonstrates basic hands-on experience with Microsoft Azure cloud services.

## What I Did
- Explored Azure Portal
- Created a Virtual Machine (VM)
- Configured basic settings for deployment
- Learned about Resource Groups
- Explored Azure Storage services

## Key Concepts Learned
- Cloud Computing Basics
- Infrastructure as a Service (IaaS)
- Resource Management in Azure
- Virtual Machines Deployment

## Tools Used
- Microsoft Azure Portal

## Outcome
This project helped me understand how cloud platforms work and how applications can be deployed and managed in a cloud environment.
